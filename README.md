# VR_dev- study project development VR trainee for tank driver
Тема проекта и аннотация


Тема проекта: VR-тренажер механика-водителя танка.
Аннотация: Приложение представляет собой обучающий VR-симулятор, моделирующий рабочее место механика-водителя танка. Цель приложения — обучение базовым операциям управления гусеничной техникой: запуск двигателя, выбор передачи, движение по различным типам покрытия и прохождение учебной трассы. Пользователь управляет виртуальной бронемашиной, используя интерактивные органы управления, проходит учебную трассу с различными типами покрытия и ограниченной видимостью. Цель — продемонстрировать базовые навыки управления гусеничной техникой в условиях, приближенных к реальным.
Цель игрока: Пройти учебную трассу, корректно используя органы управления, без критических ошибок и в установленное время.
Задачи игрока:
 – запустить двигатель;
 – начать движение;
 – пройти трассу;
 – не допустить ошибок.
Реализация:
 – один тип танка (обобщённая модель);
 – один основной сценарий прохождения трассы;
 – система оценки по времени и ошибкам.
 – режим обучения и режим экзамена;
Описание материалов, на основе которых разрабатывается проект


Проект основывается на:
 – открытых технических описаниях принципов управления гусеничной техникой;
 – материалах по подготовке механиков-водителей (общие принципы);
 – документации Unity (XR Interaction Toolkit, Rigidbody physics);

 – обобщённая модель управления гусеничной техникой;
 – анализ нескольких схем управления (классическая рычажная и современная);

Описание используемых локаций и объектов


Локация:
 Учебный полигон.
Состав полигона:
 – прямые участки;
 – повороты;
 – подъём и спуск;
 – участки с разными покрытиями.
Объекты:
 – танк (основной управляемый объект);
 – органы управления внутри кабины;
 – триплекс и люк;
 – чекпоинты;
 – зоны изменения сцепления.
Реализация:
 – полигон (рис. 1);
 – три типа покрытия (асфальт, грунт, грязь);
 – трасса на прохождение (рис. 2).

Возможности пользователя/игрока


Игрок может:
 – взаимодействовать с интерактивными объектами 
 – менять положение по вертикали (по горизонтали игрок статичен)
 – полная очистка триплекса (вылезти через люк, протереть рукой) 
Взаимодействие с танком:
рычаг переключения передач (list  -1 -> 6, 6 вперед, 1 назад, нейтраль, увеличивают крутящий момент, на каждый шаг свой момент)
педаль топлива (float 0-1, добавляет газ, увеличивает мощность двигателя, мощность * момент = обороты, коэффициент поверхности * момент - тяга, от тяги зависит скорость)
педаль тормоза (float 0-1, (1-тормоз)*тяга = скорость)
педаль сцепления (float 0-1, при изменении больше чем 0.2 в секунду - двигатель глохнет) 
рычаги блокировки гусениц (правый + левый, float 0-1, 180°*float рычага - поворот в соответствующую сторону)
индикаторы (спидометр, тахометр и т.д.)
элементы управления двигателем (только при запуске двигателя - подача топлива, воздуха - bool, надо включить и отключить в правильном порядке, иначе двигатель заглохнет)
люк мехвода (открывается\закрывается, можно вылезти из него)
триплекс - перископ для обзора, направленный вперед
загрязение триплекса - кнопка для подачи сжатого воздуха на триплексы (убирает грязь частично)

Описание механик объектов


Танк:
 – движение на основе дифференциального управления (левая/правая сторона);
 – зависимость скорости от выбранной передачи;
 – изменение коэффициента сцепления в зависимости от поверхности.
 – механики триплекса - ограничение поля зрения, визуальное загрязнение при проезде грязи, возможность очистки.
 – механика люка - возможность при необходимости открыть люк мехвода и иметь свободный обзор через него

Описание механики логики работы приложения


 – система автоматической оценки действий игрока.
 – виртуальный инструктор (голосовые подсказки или текстовые уведомления).
Описание особых взаимодействий между объектами


– Въезд в грязевую зону снижает сцепление;
 – Грязевая зона активирует загрязнение триплекса;
 – Неправильное использование передачи снижает эффективность движения;
 – Пропуск чекпоинта фиксируется как ошибка. 
Возможные ошибки:
Пропуск чекпоинта
Заглох двигатель
Выезд за трассу


Сценарии использования приложения


Сценарий 1 - Полигон:
Пользователь выбирает режим полигона в главном меню
по желанию проходит инструктаж по управлению танком
изучает открытую карту полигона со всеми механиками, типами поверхностей и препятствий
Сценарий 2 - экзамен/трасса на прохождение:
Пользователь выбирает режим экзамена
получает вводный инструктаж про условия экзамена (примерный список препятствий, ограничение по времени, условия провала)
проходит трассу
после прохождения получает отчёт о совершенных ошибках, потраченном времени и оценку экзамена
